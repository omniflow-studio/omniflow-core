## What is OmniFlow Studio?

OmniFlow Studio is an **autonomous multi-agent AI pipeline** that orchestrates the entire video production workflow from raw topic to finished CapCut Desktop timeline without any manual editing.

## The Problem

Video creators waste 80% of production time on:
- Manual research across dozens of sources
- Repetitive script writing and revisions
- Tedious voiceover recording and alignment
- Frame-by-frame timeline assembly in NLE software

## The Solution

OmniFlow replaces every manual step with an intelligent agent:

```
Topic Input
    |
    v
[Research Agent (LLM)]        <- Processes 200K+ token archives
[Script Agent (Claude)]        <- Scene-by-scene narration
[Voice Director Agent]         <- Word-level timing + Neural TTS
[CapCut Draft Compiler]        <- draft_content.json output
```

## Technology Stack

- **LLM Backbone:** Anthropic Claude (200K context) for script generation
- **Speech Synthesis:** F5-TTS, Kokoro, XTTS via NVIDIA CUDA / TensorRT
- **Pipeline Orchestration:** Python async agents with parallel execution
- **Output Format:** CapCut Desktop draft_content.json
- **Cloud Infrastructure:** Azure, NVIDIA Inception GPU credits
